# Studja 🚀

> Empowering high school graduates to navigate their future, discover career paths, and find the right college courses with confidence.

---

## 💡 About the Project

Choosing a career path right after high school can be overwhelming. **Studja** is a modern platform designed to bridge the gap between students and higher education. By combining intuitive UI/UX design with a streamlined discovery process, Studja helps students explore college programs, understand course requirements, and make informed decisions about their academic and professional futures.

---

## ✨ Key Features

- **Guided Discovery:** Interactive onboarding and assessments to help students identify their interests and strengths.
- **Comprehensive Course Catalog:** Detailed insights into different undergraduate programs, career outcomes, and university options.
- **Modern & Responsive UI:** Built with a mobile-first approach, ensuring a seamless experience across all devices.
- **Personalized Roadmaps:** Clear paths showing prerequisites, timelines, and next steps for entering desired fields.

---

## 🛠️ Tech Stack

This project is built using modern web technologies:

- **Front-End:** React, HTML5, CSS3, JavaScript
- **Back-End & Services:** Node.js, Python
- **Version Control:** Git & GitHub

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+ recommended)
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mauriciosalerafilho/studja.git
   ```

2. Navigate to the project directory:
   ```bash
   cd studja
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

## 🎨 UI/UX Philosophy

Studja is built with a strong focus on user experience (UX). The interface minimizes cognitive load during high-stress decision-making moments, utilizing clean typography, friendly micro-interactions, and accessible design principles.
